## 🚀 How to Test

### Test User Sign-Up:
1. Open `home.html` in browser
2. Click the User card → "Sign Up"
3. Fill in all required fields:
   - Full Name: John Doe
   - Email: john@example.com
   - Password: 123456
   - Confirm: 123456
   - Phone: 9876543210
4. Click "Sign Up" button
5. You'll be redirected to Sign In modal

### Test User Sign-In:
1. Click "Sign In" with the credentials you just created
2. You'll be logged into the user dashboard
3. Click the "👤 Profile" button to see your info
4. Register for events by clicking "Register" on event cards
5. Click "Logout" to end session

### Test Admin Sign-In:
1. Open `home.html`
2. Click the Admin card → "Sign In"
3. Enter any Admin ID: `ADMIN001`
4. Enter any Password: `password123`
5. You'll be logged into the admin dashboard
6. Create events using the form at the bottom
7. Click "Logout" to end session
