## 🎨 Color Interactions

### Default State
```
Button Background:    Blue (#063da2)
Button Text:         White
Border:              Light Gray (#e5e7eb)
Input Background:    White
Modal Background:    White
Backdrop:            Black 60% opacity
```

### Hover State
```
Button:              Scale up 1.05x
Button Shadow:       Blue glow effect
Input Border:        Change to Blue
Input Shadow:        Blue glow
```

### Focus State
```
Input Border:        Blue (#063da2)
Input Shadow:        Blue glow 3px
Outline:             None
Background:          White (unchanged)
```

## 🎬 Animation Timeline

### Modal Open
```
0ms   → 100ms → 200ms → 300ms
                 ↑
        Slide Down (Top -50px to 0)
        Fade In (Opacity 0 to 1)
        Complete
```

### Button Click
```
0ms   → 100ms → 150ms → 200ms
              ↑
        Scale from 1.0 to 1.05
        Add shadow
        Complete
```

## 🔄 Data Flow

### Sign-Up Flow
```
User fills form
    ↓
Submit button clicked
    ↓
Form validation checks
    ↓
Data stored in localStorage
    ↓
Success message shown
    ↓
Modal switches to Sign In
    ↓
User can now Sign In
```

### Sign-In Flow
```
User enters credentials
    ↓
Submit button clicked
    ↓
Retrieve from localStorage
    ↓
Verify credentials match
    ↓
Create session
    ↓
Store session data
    ↓
Redirect to dashboard
    ↓
User dashboard displays
```
